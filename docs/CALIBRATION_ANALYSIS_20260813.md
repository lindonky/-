## 3. 采用的双路跌倒判定

算法版本升级为 `single-leg-mvp-0.3`，两条路径彼此独立：

```text
角度路径：max(|pitch-pitch₀|, |roll-roll₀|) ≥ 65°，连续 ≥ 400 ms
加速度路径：三轴合加速度 ≤ 0.55 g 或 ≥ 1.60 g
确认条件：角度路径成立 OR 加速度路径成立
安全动作：暂停当前训练 → 上报一次跌倒事件 → 锁存急停 → T1/T2/T3 回到 1500 μs
恢复条件：人工执行 START 解除急停；不会自动恢复训练
```

65° 阈值高于系统允许的 60°小腿 ROM 硬上限，避免合法训练目标与跌倒急停范围重叠；400 ms 防抖用于拒绝短暂抬腿或侧偏。加速度路径用于比本批慢速样本更快的自由落体或冲击，不因这组数据的重叠而降到接近 1 g；单个越界样本会立即急停，这是安全优先但更容易受传感器毛刺影响的取舍。

按原始时间戳逐点回放：静止、正常抬腿和侧向偏移均不触发；慢速可控模拟跌倒在相对开始 13.59 s 时由角度路径触发。四段数据均没有触发加速度路径。

## 4. 对其他动作指标的影响

- 静止相对姿态最大约 3.3°，当前 8° 抬腿起点仍留有余量；但单段静止数据不足以证明绑带松动、温漂和水下漂移时也不会误计步。
- 正常抬腿主运动轴范围约 20.3°，落在当前 15–45° 工程目标范围内，支持保留现阶段默认值。
- 侧向样本横向范围约 26.6°，会被当前 8° 横向目标明显扣分；单个小腿 IMU 仍只能称为“横向偏移”，不能据此诊断膝外翻或侧向损伤。
- 正常抬腿和侧向偏移的合角速度峰值约 54–55°/s，模拟跌倒约 74°/s，分隔不足以单独作为可靠跌倒阈值，因此本轮不增加独立角速度判定。

## 5. 仍需验证

- 当前 JY61P 输出约 10 Hz，400 ms 仅覆盖约 5 个采样点；应在不改变波特率或造成丢帧的前提下提高 IMU 输出频率，再复测急停响应时间。
- 需要补充快速抬腿、甩腿、坐下/蹲下、治疗人员扶持、绑带松动、设备碰撞和真实水下受控失衡负样本。
- 加速度路径需要专门的安全台架自由落体/软垫冲击样本验证，禁止为了采样让患者真实跌倒。
- 软件急停不能替代独立硬件断电、机械限位、人员保护和临床风险评估。
