# JY61P 单腿标定数据采集手册

> 适用于当前 JY61P 安装在小腿中部的单腿原型。该功能是工程标定工具，不是临床测试、跌倒挑战或安全证明。

## 1. 采集了什么

每个 JY61P 有效样本直接在 ESP32 的 IMU 接收任务中记录，不经过 500 ms 网页轮询：

- 设备单调时间戳和 JY61P 样本序号。
- 归零后的 `roll/pitch/yaw`。
- 按当前安装轴配置映射的 `motion/lateral`。
- 三轴角速度 `gx/gy/gz`和三轴加速度 `ax/ay/az`。
- 俯仰/横滚控制输出、三路实际 PWM 脉宽、模式、急停和稳定开关状态。

默认固定保留 1200 个有效样本，每条 44 字节，约占 51.6 KiB 内部 RAM。具体时长由 JY61P 真实输出率决定；页面会显示实际 Hz。数据不写入 Flash，重启设备即丢失。

## 2. 安全前提

1. 首次确认轴向和纠偏方向时，拆下螺旋桨或让电机完全脱离人体与机械负载。
2. 在人体、水中或受控失衡场景中，必须有专业人员、独立硬件断电、扶持/悬挂保护和事先设定的终止条件。
3. 禁止为了生成“跌倒数据”而让佩戴者真实跌倒。需要的是受保护的失衡前后信号，不是身体落地或撞击。
4. 一次只做一种标签动作，导出后立即检查文件，再清除缓冲并开始下一次。

## 3. 推荐采集清单

每类先采 3–5 次，每次包含 5–10 个人工可数的完整动作：

| 标签 | 主要用途 | 操作要点 |
|---|---|---|
| `neutral` | 零位噪声、绑带微动 | 保持小腿中立不动 |
| `normal-lift` | 主轴、正负号、计步基线 | 正常缓慢抬起并完整回位 |
| `small-lift` | 启动阈值与微动排除 | 小幅动作，人工记录是否应计步 |
| `fast-lift` | 角速度上限、跌倒误报 | 可控的快速完整动作 |
| `lateral-offset` | 横向轴与纠偏阈值 | 明显但受控的左/右偏移，不施加疼痛或关节侧向负荷 |
| `strap-loose` | 安装松动的假动作 | 在不通电或安全台架上模拟传感器/绑带松动 |
| `controlled-instability` | 疑似跌倒多阶段阈值 | 只在完整保护条件下收集失衡前后姿态，不落地、不撞击 |

同步用手机视频拍摄，画面中展示计时器或在开始时做一个明显的同步动作，便于人工标注。视频不会由设备自动上传。

## 4. App/Web 操作

1. 连接 `AlwaysbeA` 热点，打开控制页。
2. 展开“工程控制与诊断”，在“高频标定采集”选择本次动作类型。
3. 确认 JY61P 在线，点击“开始采集”。
4. 完成本次动作，点击“停止”。缓冲满时会自动停止。
5. 点击“导出 CSV”，Android 会打开系统另存为窗口；普通浏览器会下载文件。
6. 确认 CSV 已保存后点击“清除”，再开始下一次。

CSV 文件名包含动作标签和手机时间；文件头保留 schema、标签、导出时间、设备启动 ID、样本数、时长和实际采样率。

## 5. 文本命令与 HTTP

```text
CAPTURE
CAPTURE START [label]
CAPTURE STOP
CAPTURE CLEAR
```

```text
GET /api/capture/status
GET /api/capture.csv
```

- `START` 只在采集状态为 `empty` 且 IMU 在线时成功。
- `STOP` 将有数据的采集固定为 `ready`。
- `ready` 数据在清除前不会被新采集覆盖。
- CSV 只能在 `ready` 状态下导出；导出时临时锁定快照，防止并发清除或重录。

## 6. 标定结果应如何使用

第一轮只完成工程判断：

- 确认 `motion` 是主要抬腿轴，需要时调整 `STAB_SWAP_PITCH_ROLL`。
- 确认抬腿、回位和横向纠偏的正负方向，需要时调整输出 sign。
- 从真实正常/异常分布重新确定抬腿启动、ROM、速度、横偏和回位阈值。
- 统计计步漏检、重复计数以及疑似跌倒误报，保留人工视频标注作为真值。

不得仅根据几个样本声称临床正确率、跌倒识别准确率、膝关节安全角度或患者肌力。

## 7. 离线质量检查与客观统计

仓库内置纯 Python 标准库工具，不需要安装 NumPy/Pandas：

```powershell
python firmware/tools/analyze_calibration_capture.py alwaysbea-capture-normal-lift-20260812-193000.csv
python firmware/tools/analyze_calibration_capture.py capture.csv --format json --output capture-report.json
python firmware/tools/analyze_calibration_capture.py capture.csv --format markdown --output capture-report.md
```

工具会检查和统计：

- schema、必需列与数字格式。
- 时间戳间隔、实测采样率、重复/逆序时间戳、缺失/非递增样本序号。
- 主运动/横向/原始三角轴、陀螺、加速度和控制输出的最小、最大、范围和 P95 绝对值。
- 原始角度中的主变化轴线索（只是线索，仍要与视频/物理安装核对）。
- 合加速度、IMU/急停/稳定标志。
- 主动模式所有样本的 T2 是否严格等于 1500 µs。

无警告时进程退出码为 `0`，发现数据/安全一致性警告时为 `1`，格式或文件错误时为 `2`。这个工具不会自动产生患者阈值，也不会评估临床正确率。
